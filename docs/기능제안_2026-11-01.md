# 가계부 앱 기능 보강 제안 (2026-11-01)

근거: 원본 시트 「민덕 공동 지출 관리」「덕우 예산안」 전 탭 구조 검토 + 현재 앱 코드(assets/app.js) 기능 대조.
상용 앱 비교는 Claude 일반 지식 기준(토스, 뱅크샐러드, 편한가계부, 위플, Splitwise, YNAB)이며 오늘 별도 검증하지 않았음.

## 3. 이관 데이터에서 손봐야 할 것

- 카테고리 표기 혼재: 「식비」와 「식재료」·「외식」, 「생활비」와 「생활용품」이 섞여 있음. 사전(가맹점→카테고리) 탭에도 그대로 들어감. 앱 안에서 **카테고리 병합 도구**(식비→외식 등 일괄 변경)를 만들면 통계가 바로 깨끗해짐.
- 금액이 빈 행 존재 (예: 2024-09-25 수도세). 이관된 거래에서 금액 0원 행을 찾아 보여주는 점검 화면 필요.
- 「전월 미정산금」처럼 실제 지출이 아닌 행이 거래로 들어가 있으면 통계가 부풀려짐. 정산 이력 기능이 생기면 이런 행은 정산 기록으로 옮기고 거래에서 제외.
- 날짜가 없는 행(같은 날 연속 입력)은 이관 시 앞 행 날짜를 따랐는지 확인 필요(미확인).

## 4. 추천 착수 순서

1. 검색·필터 + 카테고리 병합 도구 (데이터가 이미 1,000건이라 효과 즉시)
2. 정산 이력·부분 정산 + 분담 비율
3. 사이클별 예산 + 오늘 남은 예산
4. 통장(공금·비상금) + 부채 카드
5. 세부 품목(영수증) + 사진 첨부
6. 태그/이벤트 정산, 월간 리포트, 자동 반복 반영
