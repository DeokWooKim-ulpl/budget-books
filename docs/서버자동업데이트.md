# 서버 자동 업데이트 — 마지막 수동 배포 한 번

이걸 한 번 해 두면 그 뒤로는 Code.gs 를 붙여 넣거나 "새 버전" 배포를 할 일이 없음. Claude 가 GitHub 에 올리면 시트 서버가 스스로 받아서 새 버전으로 배포함.

원리: Google 의 Apps Script API 로 스크립트가 **자기 자신의 코드를 바꾸고 새 버전을 배포**할 수 있음. `updateServer()` 가 GitHub(`budget-books/backend/`)에서 Code.gs·Parser.gs 를 받아 교체 → 새 버전 생성 → 기존 웹앱 배포를 그 버전으로 바꿈. 주소는 그대로.

## 1회 준비 (시트 두 개 각각, 5분)

### A. Apps Script API 켜기 (구글 계정당 한 번)
1. https://script.google.com/home/usersettings 열기.
2. "Google Apps Script API" 스위치를 **사용**으로.

### B. 코드와 권한 파일 붙여 넣기
1. 시트 → 확장 프로그램 → Apps Script.
2. 왼쪽 톱니(프로젝트 설정) → "appsscript.json 매니페스트 파일을 편집기에 표시" 체크.
3. 왼쪽 파일 목록에서 `appsscript.json` 클릭 → 전체 지우고 아래 내용 붙여 넣기 (GitHub `backend/appsscript.json` 과 같음):
```
{
  "timeZone": "Asia/Seoul",
  "dependencies": {},
  "exceptionLogging": "STACKDRIVER",
  "runtimeVersion": "V8",
  "oauthScopes": [
    "https://www.googleapis.com/auth/spreadsheets",
    "https://www.googleapis.com/auth/script.external_request",
    "https://www.googleapis.com/auth/script.scriptapp",
    "https://www.googleapis.com/auth/script.container.ui",
    "https://www.googleapis.com/auth/drive",
    "https://www.googleapis.com/auth/script.projects",
    "https://www.googleapis.com/auth/script.deployments"
  ],
  "webapp": { "executeAs": "USER_DEPLOYING", "access": "ANYONE_ANONYMOUS" }
}
```
4. `Code.gs` 클릭 → Ctrl+A → GitHub 의 https://github.com/DeokWooKim-ulpl/budget-books/blob/main/backend/Code.gs ("Raw" 버튼 → Ctrl+A, Ctrl+C) 내용 붙여 넣기.
5. `Parser.gs` 도 같은 방법으로 (backend/Parser.gs).
6. Ctrl+S.

### C. 권한 허용 + 첫 실행
1. 위쪽 함수 드롭다운에서 `updateServer` 선택 → ▶ 실행.
2. "권한 검토" 창 → 계정 선택 → "고급" → "…(안전하지 않음)으로 이동" → 허용. (이번엔 권한이 늘어서 다시 물어봄.)
3. 아래 실행 로그에 "이미 최신입니다" 또는 "새 버전 N … 완료" 가 보이면 성공. 403 오류면 A 단계(API 켜기)를 확인.
4. 함수 드롭다운에서 `installUpdateTrigger` 선택 → ▶ 실행. (매시간 GitHub 확인)

### D. 마지막 수동 배포
배포 → 배포 관리 → ✎ → 버전 "새 버전" → 배포. (C 에서 "새 버전 N … 완료" 가 떴으면 이미 끝난 것이라 생략해도 됨.)

## 그 뒤
- Claude 가 코드를 고치고 GitHub 에 올리면 **1시간 안에** 두 시트가 스스로 갱신됨. 바로 하고 싶으면 시트 메뉴 "가계부 앱 → 서버 업데이트".
