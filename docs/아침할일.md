# 아침에 할 일 (2026-11-02)

밤새 앱에 새 기능이 들어갔음. 앱(프론트)은 이미 올라가 있고, **시트 서버(Code.gs)만 바꾸면 켜짐**. 서버를 안 바꿔도 기존 기능은 그대로 됨.

## 1. 두 시트에 새 서버 붙이기 (시트마다 5분)
"민덕 공동 지출 관리 (앱)" 과 "덕우 예산안 (앱)" 둘 다 똑같이:
1. 시트 열기 → 메뉴 확장 프로그램 → Apps Script.
2. 왼쪽 파일 목록에서 `Code.gs` 클릭 → 편집 창 클릭 → Ctrl+A → Delete.
3. 새 Code.gs 내용 붙여 넣기. 어디서 가져오나:
   - GitHub: https://github.com/DeokWooKim-ulpl/budget-books/blob/main/backend/Code.gs → 오른쪽 위 "Raw" → Ctrl+A, Ctrl+C.
   - 또는 PC 폴더 `09 개발·프로젝트/ledger-app/apps-script/Code.gs` (워크스페이스 pull 한 뒤).
4. `Parser.gs` 도 같은 방법으로 교체 (backend/Parser.gs).
5. Ctrl+S 저장.
6. 위쪽 함수 드롭다운에서 `setup` 선택 → ▶ 실행. (새 탭 7개가 생김: 정산, 통장, 통장거래, 부채, 이벤트, 품목, 예산. 거래 탭 끝에 분담·태그 열 추가.)
7. 오른쪽 위 **배포 → 배포 관리 → ✎(연필) → 버전: "새 버전" → 배포**. ("새 배포"가 아님! 주소가 바뀌면 안 됨.)
8. 확인: 브라우저에서 `/exec` 주소 열면 `"version":3` 이 보여야 함. (앱 더보기 → "서버 상태 보기")

## 2. 옛 탭 데이터 가져오기 (공동 시트, 선택)
시트 상단 메뉴 "가계부 앱"에서 (메뉴가 안 보이면 시트 새로고침):
- "세이프 박스 탭 → 통장 이관": 지민비상금·공금 통장과 입출금 기록이 생김. 결과 창의 잔액이 옛 탭 상단 숫자(지민비상금 1,370,621 / 공금 172,036)와 다르면 출금이 양수로 적혀 있던 것 → 앱 통장 화면에서 해당 건을 지우고 출금으로 다시 넣기.
- "대출 상환 표 → 부채 이관": 케이카 캐피탈 대출(13,727,000원, 14.2%, 36회)이 부채에 들어감. 앱 → 더보기 → 대출에서 "매달 고정 지출로 등록" 누르면 월 470,790원이 고정 항목이 됨.
- "영수증 탭 → 품목 이관": 같은 날짜·총액의 거래를 찾아 품목을 붙임. 못 찾은 영수증은 결과 창에 나옴.

## 3. 폰에서 확인
앱을 완전히 닫았다가 열기 (자동으로 새 버전 받음, 더보기 맨 아래 "앱 버전 2026-11-02a").
- 공동 장부 홈: "정산" 카드에 누가 누구에게 얼마 → "일부 보내기" / "정산 완료". 더보기 → 관리에 정산 기록·통장·대출·이벤트·카테고리 정리.
- 입력 폼: "분담"(같이 / 덕우 전액 / 지민 전액), 이벤트 태그, 세부 품목.
- 목록: 검색창. 이벤트 화면의 "거래 보기"는 태그로 거른 목록.
- 개인 예산안 홈: 예산 옆 "예산 수정" → 이번 사이클 총액·카테고리별. "하루 얼마씩" 안내.
- 더보기 → 카테고리 정리: 식비 → 외식, 생활용품 → 생활비 처럼 합치기 (이관 데이터 정리용).

## 4. 내가 정한 기본값 (바꾸려면 알려주기)
- 분담 비율 50:50 (시트 설정 탭 `SPLIT_RATIO` 를 `60,40` 처럼 바꾸면 소득 비례 가능, MEMBERS 순서).
- 통장은 이관으로 만들거나 앱에서 직접 추가. 자동으로 만들어 두지 않음.
- 사이클 예산 기본값은 설정 탭 BUDGET_TOTAL(600,000). 사이클마다 다르게 하려면 앱 예산 화면에서.
- 이벤트 정산은 전체 정산에 포함됨 (따로 떼지 않음). 여행 전에 미리 보낸 돈은 정산 화면에서 같은 태그로 기록.

## 5. 저장소
- `budget-books`(앱) 는 푸시 완료. PC 의 `[98] Github 링크/budget-books` 는 `git pull` 또는 GitHub Desktop 에서 Fetch/Pull.
- `claude-workspace`(소스) 는 이 세션에 푸시 권한이 없어 **커밋만** 해 둠. 아침에 "워크스페이스 푸시 허용"이라고 하면 올림. 그 전에는 PC 에서 작업하지 말 것 (충돌).
